# 桌面便签

简约美观的 Windows 桌面悬浮便签，支持自定义分类、富文本记录、主题切换与数据备份。

## 功能

- **悬浮桌面** — 无边框透明窗口，可置顶显示
- **收起到边缘** — 一键缩到屏幕侧边，可拖动、点击展开；拖动窗口贴近屏幕边缘也会自动收起
- **透明度调节** — 底部滑块实时调整窗口透明度，仅背景变透明，文字始终清晰
- **自定义分类** — 任意添加 / 重命名（双击标签）/ 删除分类，内容自动本地保存
- **富文本编辑** — 标题、加粗、斜体、列表、查找定位；粘贴网页内容自动净化，只保留基础排版
- **主题切换** — 标题栏 🎨 按钮在暖色 / 冷色 / 绿色间切换
- **字数统计** — 页脚实时显示当前分类字数
- **数据安全** — 内容修改 10 秒后与退出时自动备份到 `notes-backup.json`；托盘菜单可随时导出 / 导入 JSON 备份（导入前会先自动备份当前数据）
- **系统托盘** — 关闭后最小化到托盘，双击恢复；支持全局快捷键显示 / 隐藏

## 运行

```bash
npm install
npm start
```

## 快捷操作

| 操作 | 说明 |
|------|------|
| 拖动标题栏 | 移动窗口 |
| 🎨 | 切换主题（暖色 / 冷色 / 绿色） |
| 📌 | 切换置顶 |
| ◀ | 收起到屏幕边缘 |
| ✕ | 隐藏到系统托盘 |
| 透明度滑块 | 调节窗口透明度 |
| Ctrl+Alt+S | 全局显示 / 隐藏便签（应用未获焦点时也有效） |
| Ctrl+S | 立即保存 |
| Tab / Shift+Tab | 列表内缩进 / 减少缩进；正文插入缩进空格 |
| Ctrl+B / I / U | 加粗 / 斜体 / 下划线 |
| 双击分类标签 | 重命名分类 |

## 打包

```bash
npm install
npm run build          # 安装程序（推荐）
npm run build:portable # 便携版 exe
```

安装程序输出：`dist/桌面便签-Setup-1.1.0.exe`

- 支持自定义安装目录
- 自动创建桌面和开始菜单快捷方式
- 默认开启**开机自启动**（托盘右键可关闭）
- 开机启动时静默到系统托盘，不弹窗口

便携版输出：`dist/桌面便签-1.1.0.exe`（双击即用，无需安装）

## 数据与备份

- 便签数据保存在系统用户数据目录（`%APPDATA%/desktop-sticky-notes/`）
- 自动备份文件：同目录下 `notes-backup.json`，每次内容修改后与退出时更新
- 手动备份：托盘右键 →「导出便签备份」，生成包含全部分类、主题设置的 JSON 文件
- 恢复数据：托盘右键 →「导入便签备份」，导入前会先自动备份当前数据，导入有误可回退

### macOS 安装包

> **注意：** macOS 的 `.dmg` 安装包只能在 Mac 电脑上打包，Windows 无法直接生成。

**在 Mac 上本地打包：**

```bash
npm install
npm run build:mac
```

输出：`dist/桌面便签-1.1.0-x64.dmg` 和 `dist/桌面便签-1.1.0-arm64.dmg`（Intel + Apple 芯片）

**在 Windows 上通过 GitHub Actions 打包：**

1. 将项目推送到 GitHub
2. 打开仓库 → Actions → 「Build macOS DMG」→ Run workflow
3. 完成后在 Artifacts 中下载 `.dmg` 文件

首次在 Mac 上打开时，若提示「无法验证开发者」，请在「系统设置 → 隐私与安全性」中点击「仍要打开」。
